# liuliu

学习通六六助手 userscript 仓库。

## 功能

- OpenAI 兼容接口答题辅助
- 自动识别题型并生成建议答案
- 可选自动勾选答案
- **图片答题（v3.4.0）**：采集题干、选项、连线题两侧的图片，支持 OCR 文字、公式、图表和纯图片选项
- 最小化悬浮图标

## 文件

- `学习通六六助手.user.js`: 主脚本

## 图片答题

从 3.4.0 起，纯图片题不再默认随机作答，而是优先交给视觉模型识别。处理链路：

1. **采集**：从题干节点（含 legacy 标题容器）和每个选项节点提取 `data-original` / `data-src` / `src` / `srcset`，补全为绝对 URL，过滤占位图与装饰小图标并去重。纯图片选项不再被丢弃，缺少字母标记时按位置补 A/B/C。
2. **传输**：默认用 `GM_xmlhttpRequest` 把图片读成 base64 data URL 内嵌发送，避免学习通图片需要登录态或校验 Referer 导致模型端取不到图。并发 3 张、单张 12s 超时、6MB 上限、按 URL 缓存；用字节魔数 + 响应头判定真实格式，防盗链返回的 HTML 拦截页会被拒绝，SVG 与 1x1 占位图会被跳过并回退到该 `<img>` 的其它地址属性。
3. **压缩**：超过最长边阈值或约 1.5MB 的大图先用 canvas 缩放并重编码为 JPEG（白底），控制请求体积。
4. **识别**：多模态消息中每张图前带位置标签（如 `Option B image 1`），系统提示词要求先读图/OCR 再作答；含图请求可单独指定视觉模型，超时自动放宽到 90s。
5. **降级**：内嵌失败时回退图片直链；图片全部不可用且题干无文字时，按配置随机作答兜底并跳过该题，避免空转。

### 设置项

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 启用图片识别 | 开 | 需要支持视觉的模型；关闭后纯图片题走原有随机兜底 |
| 视觉模型 | 空 | 留空复用主模型；填写后仅在含图请求中使用 |
| 图片传输方式 | 自动 | 自动（优先内嵌，失败回退直链）/ 强制内嵌 base64 / 仅发送图片直链 |
| 单题最多图片数 | 6 | 上限 12；超限时按「题干 / 选项 / 连线」轮转取样，避免题干截图把选项图全挤掉 |
| 图片最长边上限 | 1600 px | 压缩阈值，文字密集的长图可调高 |
| 自动压缩大图 | 开 | 关闭后按原图内嵌 |
| 图片识别失败时随机作答 | 开 | 仅在视觉不可用、图片读取失败或重试耗尽时触发 |

模型/图片相关配置保存后会自动清空答案缓存、图片缓存和重试状态，并允许之前被跳过的图片题重新识别。

### 提示

- 图片识别需要支持 `image_url` 内容的模型（如 `gpt-4o-mini`，或各类 VL 模型的 OpenAI 兼容端点）。
- 若接口只接受公网图片链接，把传输方式切到「仅发送图片直链」。
- 第三方端点若不支持多模态或拒绝 base64，会进入重试/兜底流程，面板日志会打印具体原因。

## 使用

1. 安装支持 UserScript 的浏览器扩展，例如 Tampermonkey。
2. 导入仓库中的 `.user.js` 脚本。
3. 在脚本设置面板中填写 API Key、Base URL 和模型名称。
4. 图片题较多时，按需填写视觉模型、图片传输方式和图片数量上限。
5. 打开学习通题目页面后使用面板进行答题辅助。
